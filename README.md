# Live2D Models

Self-hosted Live2D Cubism 2 models for blog kanban girl.

## Source

- `fghrsh/live2d_api` — Pio, Tia, HyperdimensionNeptunia, Bilibili-22/33, ShizukuTalk, KantaiCollection/murakumo
- `hst1189/live2d-widget` — Rem, Kiana, Kurumi, Sakura, Index, Yuri, Bronya, Theresa, Himeko, Redeemer, Fox, Snow Miku, Platelet series, Sin, Chiaki Kitty, Mei, Moon, Live μ's

## Usage

Via jsDelivr:

```
https://fastly.jsdelivr.net/gh/Yannick-Mo/live2d-models@master/model/REMOTE_DIR/model.json
```
